# 🏰 Семья Легенд — семейный RPG-трекер


Идеи на будущее собраны в `IDEAS.md`.
Сайт для семьи: тренировки, зарядка, учёба, привычки и книги дают опыт, уровни, таланты и сундуки. Раз в неделю вся семья вместе сражается с боссом. Есть режим для телевизора. Интерфейс на русском.

Исходное ТЗ — `SPEC.md`, план и баланс — `PLAN.md`.

## Кнопки для Windows (без команд)

В папке проекта лежат файлы, которые запускаются двойным щелчком:

| Файл | Что делает |
|---|---|
| `start.bat` | Включает Docker Desktop (если выключен), запускает сайт, показывает адреса для телефона и ТВ, открывает браузер |
| `update.bat` | **Обновить и запустить**: скачивает новую версию с GitHub и сразу запускает сайт. Если папка не связана с git (например, проект скопировали без скрытой папки `.git`), сам это исправляет. Данные в папке `data` не затрагиваются |
| `stop.bat` | Останавливает сайт (данные сохраняются) |
| `backup.bat` | Делает копию базы в `data\backups` и открывает эту папку |

Если сайт не запускается, дважды щёлкните `logs.bat`: он проверит Docker, покажет состояние и последние сообщения сайта (ошибка обычно в конце), а также свободное место.

Чтобы запускать с рабочего стола: правой кнопкой по файлу → «Отправить» → «Рабочий стол (создать ярлык)». Для `update.bat` нужен установленный Git (https://git-scm.com/download/win). Ветка обновлений задана в начале `update.bat` (строка `BRANCH`); если когда-нибудь поменяется основная ветка проекта, исправьте её там. На macOS то же делает `start.command`, на Linux `./start.sh`.

**То же командой:** `docker compose up -d --build`. Сайт не стартует сам при включении компьютера: запустите его кнопкой или включите в Docker Desktop «Start Docker Desktop when you sign in» (в `docker-compose.yml` стоит `restart: unless-stopped`).

## Быстрый запуск (Docker, домашний сервер)

```bash
git clone <адрес репозитория> moy-rost
cd moy-rost
docker compose up -d --build
```

Сайт откроется на `http://<IP-сервера>:3000`. Узнать IP: `hostname -I` на сервере.

- Телефоны и планшеты открывают этот адрес в браузере.
- ТВ открывает `http://<IP-сервера>:3000/tv`.
- База хранится в папке `./data` рядом с `docker-compose.yml`, она переживает перезапуск и пересборку.

При первом запуске создаётся семья из четырёх профилей: Папа, Мама, Старший, Младший (нормы баллов 60/100 и 40/70 у младшего). Имена, эмодзи, цвета и нормы меняются в «Настройках».

## Первый вход

1. Откройте сайт, выберите профиль.
2. Нажмите «🔒 PIN» и введите **новый PIN родителей** (4–8 цифр). Если PIN ещё не задан, первый введённый становится PIN-ом, поэтому сделайте это сразу после установки.
3. В «Настройках» поправьте участников, награды сундуков и часовой пояс (по умолчанию `Asia/Novosibirsk`).

Режим родителя действует 30 минут после ввода PIN и продлевается при каждом действии родителя. После пяти неверных попыток подряд ввод блокируется на 5 минут.

Для сервера в интернете (HTTPS и пароль на весь сайт) см. [DEPLOY.md](DEPLOY.md).

## Запуск без Docker

Нужен Node.js 22.

```bash
npm install
npm run db:migrate   # создать/обновить базу в ./data/app.db
npm run db:seed      # стартовая семья и награды (если база пустая)
npm run build
npm start            # http://localhost:3000
```

Для разработки: `npm run dev`. Проверки: `npm test` (тесты игровых формул и действий) и `npm run typecheck`.

Переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DB_PATH` | `./data/app.db` | путь к файлу SQLite |
| `PORT` | `3000` | порт |
| `SESSION_SECRET` | генерируется в `data/.secret` | ключ подписи cookie |
| `BACKUP_DIR` | `data/backups` | куда писать копии |
| `BACKUP_KEEP` | `14` | сколько последних копий хранить |

## Резервное копирование

Копия делается на лету, сайт останавливать не нужно:

```bash
docker compose exec app npm run db:backup     # в Docker
npm run db:backup                              # без Docker
```

Файлы появятся в `data/backups/app-ГГГГ-ММ-ДД-чч-мм-сс.db`, хранятся последние 14.

Автоматически раз в сутки в 03:00 (на сервере, `crontab -e`):

```bash
0 3 * * * cd /путь/к/moy-rost && docker compose exec -T app npm run db:backup
```

Файл `data/backups/` лучше периодически копировать на другой диск или в облако: копия на том же диске не спасёт от поломки диска.

**Восстановление:**

```bash
docker compose down
cp data/backups/app-2026-11-19-03-00-00.db data/app.db
rm -f data/app.db-wal data/app.db-shm
docker compose up -d
```

## Как это устроено

- Next.js + TypeScript, SQLite через Drizzle. Вся игровая логика — чистые функции в `src/lib/game/` с тестами.
- **Опыт не хранится в базе**, он считается из записей за всю историю. Поэтому смена класса или таланта пересчитывает историю, а правка или удаление записи сразу меняет уровень, сундуки и босса.
- Подкласс даёт бонус по уровню, а уровень зависит от очков. Чтобы не было цикла, уровень для бонуса подкласса считается по очкам без бонуса подкласса.
- Босс недели и награды за него тоже считаются из записей и текущих норм. Если поменять норму задним числом, итоги прошлых недель пересчитаются.
- Ребёнок записывает только за себя и только за сегодня и 7 прошлых дней. Снять отметку, удалить запись, править квесты и настройки можно только с PIN.
- Ручные квесты ждут подтверждения родителя (⏳). Опыт начисляется после подтверждения. Автоквесты засчитываются по записям.

## Режим ТВ

`/tv` — крупные шрифты и высокий контраст, обновление каждые 10 секунд. Стрелки пульта двигают фокус по кнопкам квестов, Enter ставит отметку ⏳. Для автоматического открытия ТВ-страницы на старте поставьте её в закладки или домашнюю страницу браузера телевизора.

## Запись сделанного с ТВ

Внизу экрана `/tv` блок «✍️ Записать сделанное»: выберите героя (стрелками пульта и Enter) и отметьте крупными кнопками: зарядку, тренировку (+15/30/45/60 мин), учёбу по видам (+15/30/45 мин), книгу («Прочитанная книга №N», +50 очков) и привычки героя. Над кнопками сводка героя за сегодня. Права как у ребёнка на телефоне: записывать можно только себе и только за сегодня, минуты только готовые (нельзя «600 минут»), повторное нажатие ничего не удваивает. Отменить запись с ТВ нельзя: это делает родитель с PIN на телефоне. ТВ работает без входа, поэтому держите сайт в домашней сети (или за паролем, см. DEPLOY.md). Логика: `src/lib/services/tvRecord.ts`.

## Безопасность

Сайт рассчитан на домашнюю сеть. Профили детей без пароля, а страница `/tv` не требует входа (с неё можно только поставить неподтверждённую отметку ручного квеста).

**Не открывайте порт 3000 в интернет напрямую.** Если нужен доступ извне, ставьте перед сайтом обратный прокси с HTTPS (Caddy, Traefik, Cloudflare Tunnel) и по возможности ограничьте доступ к `/tv` и `/api/tv`.

## Вкладка «Тело»: упражнения и нагрузка на мышцы

Выберите упражнение из каталога (около 35: силовые, кардио, игры и спорт, растяжка) или нажмите на мышцы прямо на силуэте («Свои мышцы»), укажите минуты, и запись сохранится вместе с мышцами. На силуэте (вид спереди и сзади) мышцы краснеют тем сильнее, чем больше нагрузка за выбранный период (сегодня, 7 или 30 дней). Мышцы нарисованы с волокнами: направление линий зависит от мышцы (веер, веретено, перемычки у пресса), рисунок строится кодом из контуров в `src/lib/fibres.ts`. Нагрузка считается как минуты × вес мышцы в упражнении; веса можно поправить в `src/lib/game/muscles.ts`. Для силовых упражнений можно записывать повторы («30 раз»): у каждого упражнения своя цена повтора (например, отжимание 0,2 очка). Накрутка невыгодна, но жёсткого потолка нет: по упражнению до порога повторы идут за полную цену, до удвоенного порога за половину, дальше за четверть; за весь день первые 40 очков за повторы по полной цене, до 80 за половину, дальше за четверть. Остаётся только лимит повторов за один подход (защита от опечатки). На экране «Тело» подсказка показывает, сколько стоит следующий повтор. Цены и лимиты в `src/lib/game/muscles.ts`, кривая в `src/lib/game/reps.ts`. Минутные тренировки считаются 1 очко за минуту, как раньше.

Контуры мышц основаны на открытых данных (MIT), см. `THIRD_PARTY_NOTICES.md`.

## Звания «Восхождение»

Развитие показано как подъём в гору. 12 званий (не совпадают с классами, подклассами и талантами): Подножие (ур. 1) → Тропа (3) → Перевал (5) → Склон (7) → Утёс (9) → Хребет (11) → Ледник (13) → Пик (15) → Вершина (17) → Над облаками (19) → Небожитель (21) → Покоритель неба (23). На экране «Герой» блок «⛰ Восхождение»: гора с тропой, пройденный путь светится золотом. Каждый герой отмечен точкой на тропе и подписанной плашкой с именем и уровнем (★ — это вы) с выноской к своей точке; плашки не налезают друг на друга. Под картой список «Кто где» с местами, званиями и опытом до следующего этапа. Звание показывается рядом с уровнем в карточке героя, в выборе профиля и на ТВ. На ТВ гора «Восхождение семьи» стоит справа от босса и героев: все члены семьи на тропе, золотом светится путь до лидера. Список и уровни: `src/lib/game/ranks.ts`.

## Семейные квесты

Общая цель на день или неделю: когда она выполнена, **опыт получают все участники**. Создаёт родитель в «Настройках» → «Семейные квесты». Два типа: «вручную» (участник нажимает «Мы сделали!», родитель подтверждает) и «по очкам семьи» (засчитывается сам, когда вся семья вместе набрала заданное число очков активности: тренировки, учёба, привычки, книги, без бонусов). Квесты видны на «Сегодня» и на ТВ.

## Недельный отчёт для родителя

Страница «📊 Отчёт» (в меню только в режиме родителя, API закрыт без PIN). По каждому участнику за выбранную неделю: очки и сравнение с прошлой неделей (для идущей недели сравниваются те же дни), график по дням с линией нормы, активные дни и дни с нормой, динамика по сферам (тренировки, зарядка, учёба, привычки, книги), невыполненные квесты, новый уровень, достижения и MVP дней. Автоматические выводы разделены на «на что обратить внимание» (дни без активности, невыполненная норма, просадка сферы от 40%, повторяющиеся проваленные квесты) и «что получилось». Для семьи: общие очки, итог босса недели, MVP дней и семейные квесты. Квесты и «дни без активности» считаются только за закончившиеся дни. Кнопка «Печать» готовит страницу к печати. Правила выводов: `src/lib/services/report.ts`.

### Сезоны и рейтинг
Вкладка «🏆 Сезон». Сезон равен календарному месяцу. Рейтинг считается по очкам относительно личной нормы (очки за дни сезона ÷ (норма × дни участия); вклад одного дня не больше двух норм), поэтому у младшего те же шансы, что у старших; участник, пришедший в середине месяца, считается с дня создания. Показаны место, средний процент нормы, очки, дни с выполненной нормой и лучший день. Опыт и уровень не сбрасываются, каждый месяц начинается новая таблица.
Призы начисляются в первый день следующего месяца: победитель +3 сундука, второе место +1. Нужно участвовать не меньше 7 дней сезона и набрать в среднем не меньше 50% нормы, иначе в этом сезоне приза нет. Есть значки «Чемпион сезона» (1 победа) и «Легенда сезонов» (3 победы). Призы идут только за сезоны, начавшиеся не раньше месяца первого запуска этой версии (дата хранится в `config.season_since`), поэтому задним числом ничего не начисляется. Итоги считаются из истории, ничего отдельно не хранится. На ТВ рядом с MVP дня показан топ-3 сезона и число дней до конца. Правила: `src/lib/game/seasons.ts`.

### Моя сумка
Вкладка «🎒 Сумка». Призы из сундуков попадают в сумку и могут копиться. Три состояния: «в сумке» (лежит), «ждёт выдачи» (ребёнок нажал «🎁 Использовать», можно отменить), «получено» (родитель нажал «✔ Выдано»). Родитель отмечает «Выдано» из сумки или из «Настроек» (блок «🎁 Просят выдать приз»), может вернуть приз в сумку и отметить все призы выданными. Все старые призы после обновления окажутся в сумке: нажмите «Отметить всё выданным», если они уже получены. В сумке есть заготовка «🔮 Артефакты»: это идея на будущее (предметы с особыми свойствами), пока не работает. Состояния хранятся в `chest_opened.status` и `chest_opened.delivered_on`. Покупки магазина остаются во вкладке «Магазин».

### Защита от накруток
Жёстких лимитов на очки нет, защита мягкая:
- **Убывающая цена повторов** (см. «Тело»): чем больше повторов за день, тем дешевле каждое следующее, но очки всегда растут, нулей нет.
- **Метка «🔎 проверить»** в «Настройках»: родитель видит дни за последнюю неделю, которые выглядят необычно (день не меньше 1,5 супер-нормы и в 1,5 раза выше обычного, подход от 90% максимума, 12 и больше подходов, тренировка от 3 часов подряд или 4 часов за день). Ничего не блокируется и очки не режутся. Родитель может удалить запись или нажать «Всё в порядке»; метка исчезнет, пока очки дня не вырастут больше чем на 10%. Ребёнок видит у такого дня значок 🔎 в истории тренировок. Правила: `src/lib/game/review.ts`.
- **Потолок вклада дня в соревнования**: для MVP дня и рейтинга сезона день засчитывается не больше чем за две нормы. Очки и уровень не ограничиваются. При равенстве на потолке в MVP решает меньший id, а не накрученные очки. Константа `DAY_RATIO_CAP` в `src/lib/game/mvp.ts`.

### Наборы квестов
В «Настройках» блок «📦 Наборы квестов»: 7 готовых наборов (Будний день, Выходной, Каникулы, Спортивный день, Умный день, Творческий день, Лёгкий день) и свои. Выберите героев, «На сегодня» или «На каждый день» и нажмите «Применить». Минуты тренировки и учёбы в готовых наборах подстраиваются под норму каждого героя (база 60). В редакторе квестов тоже есть кнопки наборов (подставляют квесты в форму) и «💾 Сохранить как набор» для своих. Готовые наборы: `src/lib/game/questSets.ts`.

### Вечернее напоминание
С заданного часа (по умолчанию 19:00, меняется в «Настройках», можно выключить) на «Сегодня» появляется карточка «🌙 До нормы ещё N оч.» с подсказками, что успеть (квесты, зарядка, привычки, тренировка). Когда норма набрана, напоминание сообщает про супер-цель; при максимуме исчезает. На ТВ в то же время показывается строка «Вечер: успейте набрать норму» с остатками по каждому герою, которые ещё не дотянули до нормы. Это подсказка на странице, а не push-уведомление, поэтому работает, пока сайт или ТВ открыты. Правила: `src/lib/game/reminders.ts`.

## Вкладка «Ум»: схема мозга

Вверху вкладки «Ум» светящаяся голова-голограмма в профиль (как на рентгене: еле видны череп, глазница, челюсть, позвонки), внутри полупрозрачный мозг в анатомически правильном положении: лобная доля за лбом над глазницей, височная позади глаза над ухом, мозжечок за ухом, ствол переходит в спинной мозг позади позвонков. Сквозь кору просвечивают желудочки и лимбическая дуга. Каждая доля своего цвета и связана со своей сферой. Лобная доля: мышление, теменная: учёба, височная: языки, затылочная: книги, мозжечок: навыки, лимбическая система: творчество, ствол и базальные ганглии: привычки. Пока сфера не развита, доля тусклая и приглушённая; чем больше вы развиваете её за выбранный период (сегодня, 7 или 30 дней), тем ярче и насыщеннее её цвет и сильнее свечение. Голова светится сильнее с общей «яркостью мозга». Есть общая «яркость мозга» (45 минут развития в день = 100%). Нажатие на область выбирает соответствующий вид учёбы для записи. Кора рисуется настоящими извилинами: текстура (`public/brain/*.png`) сгенерирована по модели реакции-диффузии, которая даёт такой же лабиринтный узор, как у реальной коры, плюс рельеф и главные борозды (центральная, боковая, теменно-затылочная), складки мозжечка. Это упрощённая учебная схема, а не медицинский атлас. Область мозга и вес сфер задаются в `src/lib/game/brain.ts`.

## MVP дня

В конце каждого дня лучший в семье получает сундук 🎁. Считается не по сырым очкам, а **относительно своей нормы** (так у 7-летнего те же шансы, что у остальных), и норму нужно выполнить (≥ 100%), иначе в этот день MVP нет. Ничья: у кого больше очков. Итог дня сохраняется, когда день закончился, поздние правки записей его не меняют. Считается со дня первого запуска этой версии, сундуки за прошлые дни не начисляются. Видно на «Сегодня» (вчерашний MVP и сегодняшний лидер) и на ТВ. Победитель видит поздравление, есть значки «MVP дня» и «Звезда семьи».

## Магазин наград

Родитель создаёт награды в «Настройках» → «Магазин» (кнопка «Добавить примеры наград» создаёт готовый набор). Цена задаётся в очках или в сундуках. Ребёнок покупает на вкладке «🛍 Магазин», покупка сразу списывается и ждёт выдачи. Родитель отмечает «Выдано» или «Отменить» (цена возвращается).

Очки в кошельке — это накопленный опыт минус потраченное. Траты не снижают уровень.
