# Установка на сервер в интернете (VPS)

Схема: Caddy принимает запросы по HTTPS (бесплатный сертификат Let's Encrypt), просит логин и пароль и передаёт трафик сайту. Порт сайта (3000) наружу не открыт.

Нужно: Linux-сервер (Ubuntu или Debian), доступ по SSH, домен.

> Эта схема только для сервера. На домашнем компьютере запускайте сайт обычной командой `docker compose up -d --build` (файл `docker-compose.yml`), а `docker-compose.prod.yml` и `deploy/setup.sh` туда не нужны.

## 1. Домен

Нужно имя, которое указывает на IP сервера.

- **Бесплатно:** [duckdns.org](https://www.duckdns.org). Войдите, создайте имя вроде `moyrost.duckdns.org` и укажите IP сервера.
- **Свой домен:** добавьте у регистратора запись типа `A`, значение — IP сервера.

Проверьте, что имя уже отвечает на IP сервера: `ping moyrost.duckdns.org`. Сертификат получить без этого нельзя.

## 2. Подготовка сервера

Подключитесь по SSH и выполните:

```bash
curl -fsSL https://get.docker.com | sh
```

Откройте порты (если используется `ufw`; у некоторых провайдеров порты открываются ещё и в панели хостинга):

```bash
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable
```

## 3. Установка сайта

```bash
git clone -b claude/funny-turing-c8yf95 https://github.com/Artemkochubey/repo-girhab.git moy-rost
cd moy-rost
./deploy/setup.sh moyrost.duckdns.org
```

Скрипт спросит логин и пароль для входа на сайт (его придумываете вы, минимум 8 символов), создаст конфигурацию и запустит сайт. Через минуту откройте `https://moyrost.duckdns.org`: браузер спросит логин и пароль, затем появится выбор героя.

Дальше как обычно: «🔒 PIN» → задать PIN родителей. Если пароль забыт, запустите `./deploy/setup.sh` ещё раз с тем же доменом и новым паролем, данные сохранятся.

## 4. Перенос данных с домашнего компьютера (по желанию)

На компьютере, где сайт уже работал (в папке `moy-rost`):

```bash
docker compose exec app npm run db:backup
```

Скопируйте свежий файл из `data/backups/` на сервер и положите как `moy-rost/data/app.db`, затем:

```bash
docker compose -f docker-compose.prod.yml restart app
```

## 5. Телевизор

Откройте в браузере телевизора:

```
https://ЛОГИН:ПАРОЛЬ@moyrost.duckdns.org/tv
```

Если браузер телевизора не принимает логин в адресе или снова просит пароль, введите его в окне один раз: обычно браузер запоминает. Если не получается, выведите `/tv` на экран с телефона или используйте приставку (Android TV, Chromecast).

## 6. Обновление и копии

Обновление:

```bash
cd moy-rost
git pull
docker compose -f docker-compose.prod.yml up -d --build
```

Копия базы (раз в сутки в 03:00, `crontab -e`):

```bash
0 3 * * * cd /root/moy-rost && docker compose -f docker-compose.prod.yml exec -T app npm run db:backup
```

Скопируйте `data/backups/` на другой диск или в облако: на том же сервере копия не спасёт от его поломки.

## Безопасность

- Логин и пароль защищают весь сайт, включая `/tv`. Дети входят в профили без пароля уже за этой защитой.
- Родительский PIN — вторая защита настроек. Используйте длинные 6–8 цифр.
- Пароль на сайт не публикуйте и не отправляйте в мессенджеры с неизвестными людьми.
- Обновляйте сервер (`apt update && apt upgrade`) и входите по SSH-ключу.

## Если сертификат не выдаётся

- Домен не указывает на IP сервера: проверьте `ping`.
- Порты 80 и 443 закрыты у провайдера или в брандмауэре.
- Посмотреть причину: `docker compose -f docker-compose.prod.yml logs caddy`.
